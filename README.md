# 将棋推し活アプリ (Shogi Oshi-katsu App)

プロ棋士・女流棋士（日本将棋連盟・LPSA・無所属）を応援するための本格的な推し活・対局管理Webアプリケーションです。お気に入りの棋士の対局スケジュールや勝敗速報、通算成績、応援メモをマルチデバイス間でリアルタイムに同期・管理できます。

---

## 🚀 主な機能 (Features)

1. **推し棋士管理 & Firebase クラウド完全同期・移行**
   - 棋士・女流棋士を「推し登録」し、推しランク（本命・神推し・激推し・注目）や応援メモを設定可能。
   - 全現役棋士プロフィール、公式対局予定、2025・2026年度公式対局結果、推し棋士データをFirebase Firestoreに完全移行。
   - Googleアカウントログインにより、複数端末（Android、iPhone、Windows、Mac）間でデータがリアルタイムに完全同期・アクセスされます。

2. **対局予定・結果カレンダー**
   - 日本将棋連盟の公式対局予定や結果を月間カレンダーで一覧表示。
   - 推し棋士の本日の対局情報をダッシュボード上部にアラート表示し、見逃しを防止。
   - Googleカレンダーへの対局予定ワンクリック追加機能。

3. **棋士名鑑 & 詳細プロフィール**
   - 全現役棋士・女流棋士のプロフィール（段位、タイトル履歴、通算成績、今年度勝率、師匠・出身地・得意戦型）を網羅。
   - 年度別の対局結果および詳細な勝敗統計グラフを完備。

4. **速報・通知センター**
   - 推し棋士の対局日や勝敗結果に関する通知・速報を管理する通知センター機能。

5. **PWA (Progressive Web App) 対応**
   - ホーム画面への追加により、ネイティブアプリ感覚で素早くアクセス可能。

---

## 🛠 技術スタック (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS (v4)
- **Icons & UI**: Lucide React
- **Backend / Database**: Firebase Firestore & Firebase Authentication
- **Build Tools**: Vite PWA plugin, TypeScript Compiler

---

## 📦 インストール・開発方法 (Getting Started)

1. リポジトリのクローンまたはワークスペースを開く
2. 依存パッケージのインストール:
   ```bash
   npm install
   ```
3. 開発サーバーの起動:
   ```bash
   npm run dev
   ```
4. プロダクションビルド:
   ```bash
   npm run build
   ```
